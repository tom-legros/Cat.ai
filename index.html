      Les agents

      Pendant un chantier, le chat code tout seul à partir de ton plan. Trois agents se relaient. Clique sur un agent pour choisir qui le fait tourner.

      Étape refusée : l'ouvrier recommence, trois essais au plus. Rien ne touche ton projet : tout se passe dans une copie à part.

      Lancer un chantier

      Écris ton plan dans un fichier, ouvre un terminal dans ton projet (il doit être suivi par git), puis tape :

      catai chantier plan.md

      À la fin, tu lis le rapport et tu gardes ou tu jettes le travail.
